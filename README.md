# xue-sihui.github.io

Personal academic website for <https://xue-sihui.github.io/>.

The site is built with Jekyll and al-folio, then deployed by GitHub Actions to the `gh-pages` branch.

## Edit Content

- Homepage: `_pages/about.md`
- Site name and metadata: `_config.yml`
- Social links: `_data/socials.yml`
- CV data: `_data/cv.yml`
- Publications: `_bibliography/papers.bib`
- Projects: `_projects/`
- Blog posts: `_posts/`

## Deploy

Push changes to `main`. The `Deploy site` GitHub Actions workflow builds the site and publishes it to GitHub Pages.
